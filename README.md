# 🚀 Adam Wejman - Professional Portfolio

Welcome to the source code of my professional portfolio website! This project showcases my transition from a long-standing career as a Team Leader in the manufacturing industry to **IT Solutions Specialist & Software Developer**.

🌐 **Live Demo:** [View Portfolio Live](https://xxlis.github.io/portfolio/)

---

## 🛠️ Technologies & Features
* **HTML5 & CSS3:** Built with clean, semantic structure and modern custom properties.
* **Responsive Design:** Fully optimized for both desktop and mobile viewports using Flexbox and CSS Grid.
* **Modern UI / UX:** Implemented a dark mode aesthetic with smooth hover effects, card elevation, and glowing UI accents.
* **No External Frameworks:** Crafted entirely with pure CSS without heavy JavaScript dependencies for optimal performance.

---

## 📂 Sections Included
1. **Header & Navigation:** Fixed responsive navigation bar with brand logo and smooth anchor scrolling.
2. **Hero Section:** Introduction highlighting my dual background in industrial leadership and IT solutions.
3. **About Me:** Professional background, core competencies, location (Nieuwegein, Netherlands), and interactive statistics counters.
4. **Skills:** Visual breakdown of technical abilities ranging from frontend development to SQL, databases, and Power BI data modeling.
5. **Projects Showcase:** Direct links to my interactive digital business card (*Exercise 5*) and other technical achievements.
6. **Testimonials:** Feedback and endorsements regarding my learning speed and leadership approach.
7. **Contact Section:** Fully structured contact form and direct links to my professional profiles.
